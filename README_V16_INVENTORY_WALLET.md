# RPG Creators — v16: кошелёк и инвентарь

Основа: v15 Hidden Markers; никакие механики карты или скрытых меток намеренно не удалены.

## Что тестировать
1. Создайте предмет «Золото», количество 8. Он должен попасть в кошелёк (8 зол.), а не остаться отдельной карточкой. Аналогично серебро и медь. Предметы с похожими названиями, например «Золотое кольцо», не конвертируются.
2. При первом открытии старого персонажа ранее сохранённые стеки обычных монет конвертируются один раз. Предварительно сделайте резервную копию данных приложения для этой тестовой миграции.
3. У обычного предмета попробуйте −1, −5, +1, +5, измените название/описание/категорию/точное количество. Проверьте перезапуск приложения.
4. Из сетевой комнаты выдайте мастером деньги, купите вещь в магазине и проверьте общий кошелёк. При переключении интерфейса персонажа отображение может обновиться после повторного открытия.
5. Получите монеты из сундука, дождитесь синхронизации с мастером, переподключитесь и проверьте, что они не начислены повторно.

## Правила
- В кошельке хранится точная сумма в медных единицах: 1 золотой = 10 серебряных = 100 медных.
- Цены существующих сетевых магазинов остаются в **золотых**, поскольку именно так работал прежний баланс «монет»; серебро и медь суммируются и могут дать целый золотой.
- Мастер сохраняет контроль над покупками и магазинным балансом. Локальные изменения кошелька и получение монет отправляют только **разницу** на сервер; сервер хранит последний учтённый итог и не начисляет те же монеты повторно при переподключении.
- В текущем прототипе игрок может самостоятельно менять свои монеты из интерфейса персонажа. Для кампаний со строгим контролем экономики в будущем следует добавить настройку полномочий игрока.
- Если количество становится 0, предмет остаётся в инвентаре; удаление — отдельная операция.
- Необратимая для отображения миграция прежних монет в единый кошелёк срабатывает при загрузке персонажа. Не устанавливайте старую версию поверх обновлённых игровых данных без копии.

## Ограничения
- Изменение валюты возможно в локальном листе персонажа. LAN-клиент синхронизирует итог в фоне; во время сетевого разрыва фактический баланс мастера обновится при переподключении.
- Взаимодействия/обмен предметами и расширенные бонусы экипировки не переделывались.
- Полная Android-сборка не подтверждена: в исходном архиве отсутствует gradle-wrapper.jar, а Android SDK не доступен в данном окружении.
