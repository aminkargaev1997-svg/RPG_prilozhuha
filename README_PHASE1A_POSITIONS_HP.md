# RPG Creators — UX fixes, Phase 1A (test build)

Основа: Personal Notes v7 (с предыдущими магазинами, камерой, обменом и древом навыков).

## Готово в этой сборке

- Стабильный локальный идентификатор для каждого выбранного персонажа: временный сетевой ID больше не определяет сохранение позиции.
- Хост сохраняет координаты отдельно по комнате, персонажу и карте, возвращает последнюю карту при переподключении, не отправляя игрока принудительно в центр.
- При переключении общей карты мастер восстанавливает известную позицию каждого игрока на выбранной карте.
- Во время движения запись в память ограничена примерно одной в 800 мс, при отключении/переходе/переключении карты сохраняется последняя точка.
- Быстрые кнопки изменения HP (-2,-5,-10,-15,+2,+5,+10,+15) на экране персонажа. Значения ограничены 0..макс.
- Существующее сохранение тумана войны по ID карты не заменялось и не сбрасывалось.

## Осталось на следующих итерациях первого этапа

- Отображение HP под метками и управление HP существ мастером, включая LAN-синхронизацию.
- Отдельная карта редактирования у мастера и публикация подготовленной карты участникам.
- Запросы на допуск игроков в комнату.
- Исправление ориентации, адаптация заметок/древа в горизонтальном режиме.
- Обнаружение комнат мастеров в Wi-Fi/точке доступа без ручного IP.

## Проверка

1. Подключиться тем же персонажем, переместить его к краю карты, отключиться и зайти снова.
2. Добавить вторую карту, переместить персонажа на ней, переключиться обратно и проверить исходную точку.
3. Включить туман, стереть несколько участков, сменить карту и вернуться — туман должен сохраниться.
4. В окне персонажа развернуть здоровье, проверить кнопки +/- и границы 0..макс.
5. Повторить после перезапуска комнаты мастером. Если исходная карта отсутствует в новой комнате, восстановление карты невозможно до её повторного добавления.

Полную Android-сборку нужно проверить в Android Studio; в текущем окружении она не выполнялась.
