# RPG Creators v22 — навигация игрока

Обновление сделано на основе полной версии v21 «Two Hands Equipment».

## Изменения

1. Нажатие «Игрок» сразу открывает библиотеку героев (без промежуточного меню).
2. Кнопка «＋» сверху открывает существующий редактор создания персонажа.
3. Карточки героев показывают имя, класс, расу, уровень и HP. Нажатие на имя/карточку открывает подробности.
4. «▶ Играть» на карточке или в подробностях показывает компактную панель выбора «Обычная игра / С друзьями · LAN».
5. Выбранный герой передаётся в LAN-вход напрямую. В таком сценарии не требуется выбирать его второй раз. Автоматическое обнаружение комнат и подключение по IP остаются.
6. При выходе из сетевой игры возвращаемся к прежнему месту запуска (библиотека или подробности героя).
7. В подробностях опыт, его настройки и удаление сведены к компактным элементам; удаление по-прежнему требует подтверждения.
8. Системный «Назад» следует соответствующим экранам персонажа.
9. Вход мастера, редактор карт и сетевые механики мастера не менялись.

## Рекомендуемая проверка на Android

- Игрок → Мои герои → «＋» → создать → вернуться к списку.
- Открыть карточку → подробности → изменить опыт → вернуться назад.
- «Играть» → обычная игра → назад → подробности.
- «Играть» → с друзьями → проверить, что герой уже выбран, поиск и ручной IP доступны → выйти к тому же герою.
- Удалить тестового героя из меню «⋯» с подтверждением.
- Войти как мастер и убедиться, что создание комнаты осталось неизменным.

### Статус проверки

Структура файлов, целостность ZIP и вызовы навигации проверены статически. Полная Android-сборка и тесты на устройствах в этой среде не выполнялись: в исходном проекте нет `gradle/wrapper/gradle-wrapper.jar`, Android SDK здесь не установлен.
