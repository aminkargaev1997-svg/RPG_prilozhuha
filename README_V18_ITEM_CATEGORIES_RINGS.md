# RPG Creators v18 — категории предметов и слоты колец

На основе полного проекта **v17**. Существующие персонажи и сохранения не удаляются.

## Каталог предметов

- 200 прежних предметов сохранены; теперь их можно фильтровать **по типу** (оружие, броня, кольца, украшения, боеприпасы, расходники, инструменты, материалы, квестовые и прочее).
- Ранее каталог группировался по жанрам. Фильтр жанров сохранён **отдельно**, поэтому можно найти, например, оружие в тёмном фэнтези.
- Поиск одновременно работает по названию, описанию, типу и жанру.
- В карточках базы показываются категория и готовые эффекты (если они есть). Категория не создаёт магический бонус автоматически.
- При выборе предмета из базы его категория копируется в инвентарь, сундук и магазин; при добавлении мастером к игроку она также передаётся.
- В ручном редакторе предмета можно выбрать категорию, в том числе **«Кольца»**. Старые предметы и вручную выбранные категории не перезаписываются.

## Кольца

- В «Экипировке» появился сворачиваемый раздел **«Кольца (0/2)»** — левая и правая рука.
- Прежний слот «Аксессуар» сохранён для совместимости.
- В новые слоты можно надеть только предметы с категорией «Кольца» либо названием «кольцо/перстень»; оружие, щит и другие вещи не подходят.
- У каждого нового кольца собственная запись в инвентаре. Один и тот же предмет нельзя надеть в два слота одновременно; для двух одинаковых колец создайте два отдельных экземпляра.
- Пока кольца не занимают основной слот рук: их можно носить одновременно с оружием/щитом. Бонусы от двух разных колец учитываются обычным механизмом ItemEffectEngine.
- Мастер может просматривать и изменять оба новых слота через уже существующее окно управления персонажем.

## Проверка в Android Studio

1. Открыть каталог предметов → выбрать фильтр «Оружие», затем «Кольца», затем вернуть «Все».
2. Выбрать «Кольцо договора» из городского фэнтези и добавить в инвентарь.
3. Открыть экипировку → «Кольца» → надеть кольцо на левую руку; попробовать выбрать меч для правой (не должен предлагаться).
4. Создать **другое** кольцо, добавить ему `+1 к Ловкости` в «Свойства и эффекты», надеть на правую; проверить подсчёт бонуса.
5. Снять/надеть его снова и перезапустить приложение; проверить оба слота и расчёт.
6. Проверить окно редактирования персонажа мастером в сетевой игре — оба новых слота должны быть доступны.

## Ограничения проверки

Код каталога, классификации, расчёта бонусов и ограничений слотов скомпилирован и проверен независимыми Kotlin-тестами. Полную Android/Compose-сборку здесь провести не удалось: в исходном архиве отсутствует `gradle-wrapper.jar` и Android SDK. Поэтому проверьте компиляцию в Android Studio и сообщите первую ошибку, если она появится.
