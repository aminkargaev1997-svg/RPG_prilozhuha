# RPG Creators — LAN-прототип

Добавлено:
- Кнопка «Сетевая игра (LAN)» на главном экране.
- Создание комнаты на телефоне хоста (TCP, порт 8988).
- Подключение других телефонов по локальному IPv4-адресу хоста.
- Автоматическая передача изображения карты (до 4 МБ) новым участникам.
- Общие координаты меток игроков на карте, перемещение касанием/перетаскиванием.
- Отдельный сетевой режим; локальная библиотека карт и сохранения не меняются.

Проверка:
1. Установить приложение на два Android-телефона и подключить их к одной Wi-Fi сети.
2. На телефоне хоста создать персонажа и добавить карту в библиотеку обычной игры.
3. Открыть «Сетевая игра (LAN)», выбрать персонажа и карту, нажать «Создать комнату».
4. На втором телефоне выбрать «Подключиться», указать IP, показанный на телефоне хоста.
5. Перемещать метки на карте и проверять синхронизацию на обоих экранах.

Ограничения первого прототипа:
- Не работает через интернет без локальной маршрутизации/VPN.
- В сети без доступа устройств друг к другу (изоляция клиентов Wi-Fi) подключение невозможно.
- Карты передаются в Base64 в рамках одной JSON-строки, поэтому ограничены 4 МБ.
- Нет переподключения, пароля комнаты, шифрования, сохранения сетевой сессии.
- Сервер работает, пока открыт сетевой экран на телефоне хоста.
- Координаты синхронизируются, но персонажи/инвентарь/боевые действия пока не синхронизируются.
- Для Android 13+ некоторые ограничения локальной сети зависят от настроек устройства.
- Сборка APK и тестирование на реальных устройствах в этой среде не выполнялись.
