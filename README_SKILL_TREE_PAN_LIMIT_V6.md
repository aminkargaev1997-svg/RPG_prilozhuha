# RPG Creators — ограничение перемещения древа навыков (v6)

Исправлено в `app/src/main/java/com/example/rpgcreators/SkillTreeScreen.kt`:

- Древо навыков больше нельзя полностью увести за видимую область неограниченным перетаскиванием.
- Границы перемещения рассчитываются из размеров Canvas, масштаба и координат крайних узлов.
- Если древо меньше экрана по одной из осей, оно автоматически центрируется по этой оси.
- Границы пересчитываются после масштабирования и изменения размеров окна (например, поворот устройства).
- При жестах масштабирования и перемещения используются актуальные размеры Canvas.
- Обработка касания узла не перезапускается при каждом кадре перемещения.
- Кнопка «Центр» по-прежнему возвращает исходный масштаб (0,58) и центральное положение.

Данные навыков, стоимость, сохранение персонажей и остальные экраны не изменены.

## Проверка на телефоне

1. Открой древо навыков, проведи пальцем далеко вверх, вниз, влево, вправо: всю схему вывести за экран больше нельзя.
2. Приблизь древо двумя пальцами и повтори; должна оставаться возможность дойти до крайних узлов.
3. Уменьши древо и проверь, что оно центрируется, когда помещается целиком.
4. Нажми «Центр» и проверь восстановление нормального положения.
5. Нажми на крайний узел: окно навыка должно открыться.

## Проверка сборки

Алгоритм ограничения отдельно проверен компилятором Kotlin и 160 автоматическими проверками геометрии на разных размерах и масштабах. Полная Android-сборка в этом окружении не выполнялась.
