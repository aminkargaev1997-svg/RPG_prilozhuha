# RPG Creators — v24. Баланс очков древа навыков

## Новое древо (buildVersion = 2)

- На первом уровне: 3 очка.
- На каждом следующем уровне вплоть до 20-го: +1 очко.
- На 20-м уровне при каждом полном заполнении шкалы опыта: +1 очко.
- Максимум очков определяется суммой стоимости всех изучаемых узлов (без центрального корня). Для текущего древа из 25 узлов максимум равен 66 очкам.
- Выдача очков мастером по LAN также учитывает этот максимум. При попытке выдать больше начисляется лишь доступный остаток; при заполненном лимите новые очки не добавляются.
- Текущий бюджет и оставшиеся очки никогда не превышают суммарной стоимости древа.

## Старое древо (buildVersion = 1)

- Сохранены прежние правила: 3 очка в начале, +2 за уровень, +2 за заполнение шкалы после 20-го.
- Старое дерево, сохранённые ID навыков и их стоимость не менялись.

## Сохранения

- Изученные ранее навыки **не сбрасываются**, даже когда их стоимость превышает изменившийся бюджет нового древа.
- При таком расхождении новые навыки временно недоступны, пока не появится достаточное количество очков.
- Неизученные очки существующего героя v23 пересчитываются по правилам v24.
- Исправлено сохранение `buildVersion` при редактировании персонажа.
- Формат сохранений SharedPreferences не изменён.
