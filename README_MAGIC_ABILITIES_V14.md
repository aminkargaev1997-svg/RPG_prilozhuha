# RPG Creators v14 — интеграция магии в способности

- Удалена кнопка отдельного листа D&D, не удалены его прежние сохранённые данные.
- КД отображается и редактируется в обычном экране персонажа. Проверки объединены по характеристикам, редактирование владения — по раскрытию.
- Ячейки заклинаний отображаются заполненными/пустыми кружками в верхней части экрана «Способности».
- «Настроить» позволяет задать максимальный запас ячеек каждого круга (до 20). Это ручная настройка; она не зависит автоматически от класса и уровня.
- Новая способность: обычная / заговор без слота / заклинание I–IX круга.
- Заклинание тратит одну ячейку своего круга, не ставится на перезарядку пока есть слоты. Заговор не тратит ячейки. Обычная способность использует прежнюю боевую перезарядку/активатор.
- После лагеря при начале дня все круги восстанавливают текущие ячейки до максимума; управление магическими слотами сохранено в прежнем DndSheetStorage.
- Ранее созданные способности остаются обычными, поскольку их тип магии в старой модели не хранился. Их автоматическая миграция в магические без согласия игрока не производится.

## Проверить

1. Открыть персонажа, затем «Способности». Задать 2 ячейки I круга.
2. Добавить «Заклинание», круг I, применить дважды. Круги должны стать пустыми; третье применение недоступно.
3. Проверить, что обычная активная способность остаётся на прежней перезарядке.
4. Запустить лагерь и начать новый день за мастера. Ячейки должны восстановиться после принятия сетевой команды отдыха.
5. Выключить и повторно запустить приложение — ячейки и типы новых способностей должны сохраниться.

## Ограничения

Нельзя гарантировать Android-сборку в текущем окружении: проект содержит скрипт gradlew, но не содержит gradle/wrapper/gradle-wrapper.jar. Код ещё необходимо собрать и проверить в Android Studio. Прежняя отдельная форма листа D&D остаётся в исходниках для совместимости и возможного переноса настроек, но кнопка открытия удалена. Общая сетевая передача магических слотов мастеру в этой версии не реализована.
