# RPG Creators — скрытые метки и зоны обнаружения (v15)

## Как проверить

1. У мастера создайте комнату и обычную карту, подключите второго игрока на новой версии приложения.
2. В «Метки» создайте метку, поставив «Скрыть от игроков до обнаружения», либо откройте «Правка» существующей метки → «Скрытность и обнаружение».
3. В свойствах выберите «Игрок входит в область», «Вся группа» либо «Только обнаружившему», форму «Круг» или «Прямоугольник». Для настройки нажмите «Нарисовать область на карте» и перетащите палец от центра метки к краю зоны; нажмите «Сохранить область».
4. Проверьте, что метка видна мастеру (фиолетовый значок ◈), но НЕ видна игроку до пересечения области.
5. Двигайте персонажа через область. Должна открыться метка; в личном режиме — только у обнаружившего игрока.
6. Пробуйте другую карту, выход из комнаты, переподключение: раскрытие и координаты должны сохраняться.
7. В редакторе метки проверьте «Раскрыть всем сейчас» и «Снова скрыть (сброс обнаружения)».
8. Для режима «Игрок наступает на метку» используется очень маленькая область вокруг центра; для «Только мастер вручную» автоматического обнаружения нет.

## Правила реализации

- Существующие типы меток НЕ меняются; скрытность — необязательное дополнительное свойство любой метки.
- Параметры зоны хранятся в нормализованных координатах самой карты (масштабирование камеры не влияет).
- Сервер мастера фильтрует списки меток по каждому игроку. Нераскрытые метки не должны приходить в сетевых пакетах `markers`.
- Личное обнаружение связано с постоянным ID персонажа, а не временным ID подключения.
- Туман войны остаётся авторитетным: если центр скрытой метки ещё закрыт туманом, автоматическое обнаружение не происходит.
- При попадании в зону метка раскрывается без автоматической атаки, урона и броска кубиков.

## Ограничения первой версии

- Зоны — эллипс/прямоугольник, без свободного многоугольника и учёта стен.
- Для создания сложных сценариев с несколькими триггерами понадобится отдельный редактор событий в будущем.
- При создании скрытой метки начальная зона стандартная; мастер может настроить её визуально в «Правка».
- Полная компиляция Android не проверена в этом окружении: отсутствует Android SDK/готовый Gradle Wrapper JAR. Тест геометрии обнаружения отдельно прошёл.
