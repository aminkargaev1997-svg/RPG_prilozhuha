# LAN-режим: игровая функциональность и общие метки

- В сетевой комнате появились вкладки «Общая карта», «Играть», «Способности».
- Вкладка «Играть» использует существующий GameScreen персонажа (инвентарь, характеристики и прочие функции).
- «Способности» открывают существующий экран способностей персонажа.
- Карта, положение персонажей и созданные метки передаются всем участникам комнаты.
- Для создания метки нажми «＋ Метка», затем место на карте; укажи название, тип, описание.
- При нажатии на точку игрока открывается окно с его именем.
- Проценты координат игроков больше не показываются.
- Кнопка «Развернуть карту» открывает увеличенное диалоговое представление карты.
- Метки пока существуют только во время текущей сетевой комнаты; сохранение сетевых меток после выхода не реализовано.
- Локальные данные персонажа и функции GameScreen не синхронизируются между телефонами; каждый использует данные своего персонажа.
- Сетевой протокол без авторизации; использовать только в доверенной локальной сети.

Сборка APK и тест на телефонах в этой среде не выполнялись.
