# RPG Creators — постоянное перемещение игрока (v3)

Основа: Adventure World UI/Exits/Story Fix v2. Все функции предыдущей версии сохранены.

## Изменено

- Когда участник подключён к LAN-комнате и его персонаж появился на карте, джойстик активен сразу. Больше не нужно нажимать на метку игрока и выбирать «Переместить».
- У обычного игрока нет кнопки «Готово» для собственной метки персонажа: джойстик остаётся доступным после завершения каждого жеста.
- Игрок продолжает перемещать **только свой персонаж**; управление чужими персонажами и метками остаётся за прежними правами и действиями.
- Если игрок выбрал режим перемещения собственной метки (если мастер разрешил), джойстик временно перемещает эту метку; «Готово» автоматически возвращает управление персонажем.
- Перемещение через туман войны по-прежнему проверяется и локально, и сервером мастера. При отпускании джойстика последняя допустимая позиция отправляется независимо от ограничения частоты сетевых обновлений.
- Мастер по-прежнему может отдельно выбирать игрока и перемещать его; этот режим завершается кнопкой «Готово».

## Тестирование

1. Подключиться к комнате как игрок; не нажимая на свою метку, провести по джойстику. Персонаж должен двигаться.
2. Отпустить палец, затем снова провести по джойстику — перемещение должно начаться сразу.
3. Нажать свою метку: вместо «Переместить» будет подсказка о постоянном джойстике.
4. Открыть другой экран и вернуться к карте, а также войти через дверь на другую карту — джойстик должен остаться доступным.
5. Установить закрытый туман и проверить, что за границу закрытой области проходить нельзя.
6. Если участнику разрешено двигать собственную метку, выбрать её и нажать «Двигать», затем «Готово»: джойстик снова управляет персонажем.
7. За мастера проверить старое поведение: выбор игрока -> «Переместить» -> «Готово».

## Примечание

Тестировалась логика исходников; полноценная Android-сборка в данной среде недоступна без Android SDK и Compose-зависимостей. Установите обновление на обе стороны LAN для согласованности тестирования, хотя сетевой формат движения не менялся.
