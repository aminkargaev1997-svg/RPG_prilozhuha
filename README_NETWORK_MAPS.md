# RPG Creators — проект с обновлением сетевых карт

Это полный проект Android Studio, собранный на основе пользовательского архива `RPG_prilozhuha-master (1).zip`.

Обновлены классы:
- `LanGameScreen.kt` — управление картами сетевой комнаты.
- `LanNetworking.kt` — передача карт, меток и позиций по LAN.
- `MainActivity.kt` — обозначение сетевых карт в библиотеке.

Добавлен класс:
- `LanRoomStorage.kt` — локальное сохранение сетевых карт и меток.

## Как открыть
1. Распакуйте архив.
2. В Android Studio выберите Open и укажите папку `RPG_prilozhuha-master`.
3. Дождитесь Gradle Sync и запустите сборку.
4. Для сетевой игры установите обновлённое приложение на устройства мастера и игроков.

Примечание: полноценная сборка Android в рабочем окружении не запускалась; необходимо проверить Gradle Sync/Build в Android Studio.
