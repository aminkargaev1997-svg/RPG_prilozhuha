# RPG Creators — Журнал заданий и улучшенный инвентарь (тестовая версия)

## Обычная игра
В игровом экране персонажа есть кнопка «Журнал заданий». Игрок может создавать, менять и удалять личные задания. В инвентаре автоматически показан неудаляемый «Журнал приключений»; нажатие на него открывает тот же журнал. В режиме удаления он остаётся заблокированным.

## Сетевая игра
Мастер выбирает «Задания» в выдвижной панели и открывает редактор. Можно назначить всей группе или по отображаемому имени подключённого игрока, скрывать публикацию, управлять целями, статусом и наградой. Игрок открывает вкладку «Журнал» или кнопку слева на полноэкранной карте. В сети журнал игрока доступен только для просмотра. Награды не выдаются автоматически.

ВАЖНО: для первой версии личное назначение по отображаемому имени (не по постоянному ID). Не выбирайте одинаковые имена у разных игроков. Личные задания мастера назначаются из списка подключённых игроков. Задания мастера сохраняются на его устройстве, полученные задания сохраняются у игроков при синхронизации. Скрытые задания не передаются игрокам.

## Инвентарь
В обычном экране персонажа доступны поиск, категория, сортировка и переключение «Поле/Список». Старое поле с перетаскиванием сохраняется; при количестве более восьми предметов автоматически открывается список. Новые предметы могут иметь категорию. «Журнал приключений» нельзя удалить.

## Проверки
Полная Android-компиляция не выполнялась: Gradle wrapper 9.6 недоступен в офлайн-среде. Соберите проект в Android Studio. Для LAN устанавливайте обновление на все устройства.
