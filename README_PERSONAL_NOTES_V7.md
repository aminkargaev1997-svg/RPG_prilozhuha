# RPG Creators · Личные заметки v7

## Что добавлено
- Экран «Заметки» в обычной игре (рядом с журналом заданий).
- Экран «Заметки» в сетевой игре (в меню персонажа и слева на полной карте).
- Создание, редактирование, поиск по заголовку и содержимому, подтверждение удаления.
- Отдельные записи для каждого персонажа, локально на устройстве.
- Проверка на случайный выход из редактора при несохранённых изменениях.

## Что важно
- Заметки **не синхронизируются** через LAN и **не доступны мастеру**.
- Заметки сохраняются в Android SharedPreferences. При удалении данных приложения они пропадут; отдельный экспорт пока не реализован.
- Никакие механики предметов, торговли, движений, карт или способностей не изменялись.

## Проверка
1. В обычной игре открыть персонажа → «Заметки» → «+ Запись», создать заметку и сохранить.
2. Открыть заметку, отредактировать и проверить поиск по тексту.
3. Нажать «Назад» с несохранённым текстом; появится предупреждение.
4. Подключиться к сетевой игре, открыть «Заметки», проверить сохранённую запись у того же персонажа.
5. Проверить, что у другого персонажа список заметок отдельный.

Полная Android-сборка в окружении не выполнялась: окончательно проверяйте проект в Android Studio.
