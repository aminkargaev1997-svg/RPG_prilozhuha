# RPG Creators — база и удаление карт из сетевой комнаты

## Что изменилось

- **Расы и классы.** При создании/редактировании персонажа появились кнопки «Выбрать из базы». В справочнике есть разделы, поиск и короткие описания; свои значения по-прежнему можно вводить вручную. Поле `profession` используется и для профессий, и для классов, чтобы существующие сохранения продолжили работать.
- **Управление персонажами мастером.** В редактировании имени/расы/класса мастер также может открыть те же справочники.
- **База меток.** В локальной карте и сетевой комнате есть кнопка «База меток и противников». Выбор шаблона подставляет название, описание и тип метки, после чего всё можно отредактировать. Это **не** полноценные карточки противников со статистиками.
- **Дополнительные типы меток.** Появились «Атака», «Защита», «Укрытие», «Ловушка», «Лечение», «Портал» и другие.
- **Удаление карты из LAN-комнаты.** Только мастер переключается на нужную карту, нажимает «− Удалить» и подтверждает. Карта исчезает у всех подключённых участников. Если удалена активная карта, происходит переключение на следующую доступную; если удалена последняя — комната остаётся открытой, мастер может добавить следующую.

## Важное о сохранении

**Удаление из комнаты не удаляет файлы карт или метки из локальной библиотеки.** Это специально: ранее посещённую сетевую карту игрок по-прежнему сможет открыть офлайн. Список карт в текущей комнате хранится в памяти работающего мастера; при создании новой комнаты карты добавляются заново. История созданных персонажей, их инвентарь и способности не сбрасывается.

## Как проверить

1. Создать персонажа, открыть базы рас и классов, выбрать варианты, сохранить и открыть редактирование.
2. Создать LAN-комнату на телефоне мастера, подключить второй телефон к этой же Wi-Fi/точке доступа.
3. Добавить 2 карты и убедиться, что выбор активной карты и метки синхронизируются у обоих.
4. На телефоне мастера удалить одну карту, согласиться с подтверждением, проверить исчезновение из списка комнаты у обоих телефонов.
5. Удалить последнюю карту: соединение должно сохраниться. Добавить новую, проверить её появление у игрока.
6. Открыть локальную библиотеку карт на обоих телефонах: удалённые из комнаты сетевые карты остаются доступными с последними локально сохранёнными метками.
7. Открыть панель новой метки, выбрать шаблон («Скелет», «Засада», «Точка защиты»), разместить и проверить название и описание.

## Для Android Studio

Откройте папку проекта `RPG_prilozhuha-master`, синхронизируйте Gradle и соберите приложение. Используется прежняя конфигурация Gradle и пакет `com.example.rpgcreators`; новых зависимостей нет.
