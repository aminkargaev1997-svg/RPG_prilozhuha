# RPG Creators — UX Phase 1B: HP и подготовка карты

Основа: UX Phase 1A v8 (позиции игроков + быстрые кнопки HP).

## Что изменено
- HP игроков синхронизируется с `AdventureVitalsStorage` через безопасный character snapshot и рассылается в составе списка игроков (`hp`, `maxHp`). Мастер нажимает на игрока, меняет HP быстрыми кнопками −2/−5/−10/−15 и +2/+5/+10/+15; изменение исполняется на устройстве владельца персонажа через `master_edit` (`adjust_health`). При отсутствии snapshot кнопки управления HP не показываются.
- HP существ хранится у сетевых меток (`LanMarker.hp`, `maxHp`), сохраняется в `LanRoomStorage` и синхронизируется с клиентами. По умолчанию 10/10 для типов Враг, Босс, NPC, Союзник, Игрок, Торговец (можно изменить мастером). Для обычных объектов HP не отображается.
- У меток и игроков HP показывается небольшой подписью на карте, а не полоской здоровья.
- Выбор карты в панели мастера теперь означает **просмотр/подготовку**, а не немедленное переключение всех игроков. Для общего перехода появилась кнопка «Показать карту всем». При добавлении новой карты она тоже не публикуется автоматически.
- Подготовка не перемещает метки игроков; при публикации действуют уже существующие правила восстановления позиций на выбранной карте.
- Сохранение тумана остаётся раздельным по каждой карте; можно стирать/закрывать туман на карте в подготовке.

## Проверить в Android Studio и на телефонах
1. Подключить мастер + игрок. Подпись HP игрока появится после получения снимка персонажа. Нажать игрока мастером; −5; проверить обновление у обоих и в окне персонажа.
2. Создать метку «Враг», увидеть 10/10; изменить максимум и текущий HP, проверить повторное открытие и перезапуск комнаты.
3. Добавить вторую карту мастером. Игрок должен остаться на первой, мастер — видеть вторую. Поставить метку и изменить туман на второй карте. Нажать «Показать карту всем»; проверить открытие второй карты у игрока.
4. Возврат на первую карту: позиции и туман должны быть восстановлены. Переподключить игрока и проверить ту же позицию.
5. Удалить **неопубликованную** карту: игрок должен остаться на текущей.

## Известные ограничения
- Полная сборка APK и тест LAN на реальных Android-устройствах в этом окружении не проводились.
- Режим приёма новых игроков по подтверждению мастера (лобби), автоматическое обнаружение комнаты, поворот экранов и масштабное обновление листа персонажа остаются следующими частями этапа 1/2.
- Для изменения HP игрока мастер должен дождаться первого snapshot этого игрока после подключения.
- Автоматически определяемые 10 HP у старых NPC — стартовое значение, не официальная характеристика D&D.
