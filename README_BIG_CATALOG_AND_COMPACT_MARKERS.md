# RPG Creators — расширенная RPG-библиотека и удобные метки

Этот выпуск создан на основе `RPG_Creators_Full_Project_Catalog_Maps.zip`.
Сетевая комната, удаление/переключение карт, управление персонажами мастером,
сохранения карт и меток оставлены без изменений.

## База

Проверенные итоговые количества (включая прежние элементы):
- 276 рас и разновидностей разумных существ;
- 274 класса и профессии;
- 367 шаблонов меток (противники, NPC, локации, объекты, события, тактика).

Десять тематических направлений:
1. Классическое фэнтези
2. Тёмное фэнтези
3. Киберпанк
4. Космическая фантастика
5. Постапокалипсис
6. Стимпанк
7. Мифология
8. Мистика и ужасы
9. Восточное фэнтези
10. Современное городское фэнтези

Элементы имеют короткие описания. Классы и расы не назначают статистику,
заклинания и предметы автоматически. Свои названия по-прежнему можно вводить вручную.
Монстры — **только шаблоны обычных меток**, а не отдельные профили существ.

## Интерфейс меток

`RpgCatalogPicker.kt` — новый адаптивный каталог:
- **альбомная ориентация:** почти на весь экран; слева прокручиваемые категории,
  справа список с описаниями, поиском и фильтром жанра;
- **книжная ориентация:** список на доступную высоту и выбор категории из меню;
- список строится через `LazyColumn`, поэтому не создаёт сотни строк сразу;
- нет прежнего фиксированного ограничения списка 330 dp.

`MainActivity.kt` — на личной карте вместо широкой сетки типов меток
появилась компактная панель с кнопкой каталога и прокручиваемым списком типов.
На сетевых картах используется тот же адаптивный каталог.

## Что изменено

- `app/src/main/java/com/example/rpgcreators/RpgCatalog.kt` — сохранена старая база,
  объединены новые записи и категории; старые вызовы API не изменены.
- `app/src/main/java/com/example/rpgcreators/RpgCatalogData.kt` — новый файл с расширенной базой.
- `app/src/main/java/com/example/rpgcreators/RpgCatalogPicker.kt` — новый файл с адаптивным UI.
- `app/src/main/java/com/example/rpgcreators/MainActivity.kt` — компактный выбор типа метки на карте.

## Проверка и запуск

Справочники отдельно скомпилированы Kotlin-компилятором и проверены по количеству
элементов и жанров. **Android-приложение целиком в этом окружении не собиралось:**
Android SDK и скачанная Gradle 9.6 здесь отсутствуют.

Открой папку `RPG_prilozhuha-master` через Android Studio и выполни Gradle Sync.
Если появляется `SDK location not found`, создай `local.properties` в корне
проекта с реальным путём к установленному SDK, например:

    sdk.dir=C:/Users/ИМЯ_ПОЛЬЗОВАТЕЛЯ/AppData/Local/Android/Sdk

Затем собери приложение и проверь каталог в книжной и альбомной ориентациях.
