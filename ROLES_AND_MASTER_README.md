# RPG Creators — роли игрока и мастера (LAN-прототип)

## Главное меню
- «Игрок» → создать персонажа, мои персонажи, сетевая игра (подключение к мастеру).
- «Мастер» → создать сетевую комнату с выбранной картой, без создания персонажа.

## В комнате
- Мастер создаёт, перемещает и удаляет любые обычные метки.
- Мастер может выбрать точку любого игрока и переместить её.
- Игрок перемещает только свою точку; сервер определяет игрока по сокету.
- Игроки не могут создавать, перемещать или удалять обычные метки без разрешения мастера.
- Мастер меняет разрешения в любое время через «⚙ Права»: создание меток, перемещение своих меток, удаление своих меток. Новые настройки отправляются всем участникам и проверяются сервером.
- Созданные игроками метки имеют ownerId (идентификатор соединения), который устанавливает сервер; клиент не может назначить себе чужую метку.
- Журнал мастера: подключение/отключение, создание и удаление меток, изменение прав; сообщения от клиента о добавлении предмета, способности, удалении способности и получении XP через сетевой экран.

## Важно — ограничения текущего прототипа
- Журнал хранится в оперативной памяти мастера и пропадает при закрытии комнаты.
- Изменения инвентаря/способностей/XP по-прежнему локальные; клиент отправляет событие, сервер не сверяет его с централизованной базой персонажей. Поэтому события не являются защищённым аудитом.
- XP, добавленный вне сетевой комнаты, не отправляется мастеру; в сетевой вкладке персонажа добавлена отдельная кнопка «+ XP» с отправкой события.
- Журнал пока не покрывает все изменения персонажа (например, редактирование существующего предмета, изменение атрибутов и некоторые действия в бою).
- Роли действуют для текущего запуска экрана; нет пароля комнаты, авторизации, постоянных учётных записей или внешнего сервера.
- Общие метки существуют только в пределах комнаты, не сохраняются после выхода.
- Использовать только в доверенной локальной сети.
- Сборка APK и тестирование на телефонах в текущем окружении не проводились.
