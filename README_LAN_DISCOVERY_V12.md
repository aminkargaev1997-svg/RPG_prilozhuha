# RPG Creators v12 — автоматический поиск комнат в LAN

- Мастер запускает комнату как прежде; приложение объявляет TCP-сервис через Android NSD и отвечает на UDP-запросы на порту 8989.
- Игрок открывает сетевую игру на том же Wi-Fi или точке доступа и выбирает комнату из списка; соединение использует прежний TCP-порт 8988 и прежний протокол.
- Если Android блокирует обнаружение или сеть изолирует клиентов, раскройте «Дополнительно: подключение по IP».
- Для тестирования устанавливайте v12 и мастеру, и игроку. С прежними версиями автоматический поиск недоступен, хотя ручной IP остаётся.
- Отдельного подтверждения входа мастером нет.
- Обнаружение работает только в локальной сети и не публикует комнаты в интернете.
