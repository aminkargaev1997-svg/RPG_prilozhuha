# RPG Creators — мастер редактирует персонажей игроков

## Что изменилось
- Нажатие на метку персонажа на карте -> «Управлять персонажем» или «Управлять способностями».
- В редакторе мастер может менять имя, расу, класс, уровень, текущий опыт, максимальный опыт и характеристики.
- Мастер может добавлять/редактировать/удалять предметы и способности и менять экипировку выбранного игрока.
- Хост отправляет изменения только выбранному игроку по его существующему TCP-соединению; данные сохраняются на устройстве игрока. Сервер принимает подтверждения и пишет результаты в журнал.
- Обновлённое состояние персонажа отправляется мастеру обычным механизмом snapshots (примерно за 900 мс).
- Исправления для LAN через мобильную точку доступа сохранены.

## Опыт
- Новые персонажи: автоматический максимум XP = 650 + 750 * (уровень - 1), уровень 1 -> 650, уровень 2 -> 1400 и т.д.
- Опыт переносится на следующий уровень с остатком.
- Старые персонажи сохраняют прежний вручную установленный максимум XP, пока игрок или мастер не включит «Авто XP».
- Если изменить максимум XP вручную, для персонажа отключается автоматическая формула.

## Важно
- На телефонах мастера и игроков должна быть установлена **одна и та же новая версия** приложения.
- Редактирование доступно для текущего персонажа подключённого игрока (того, который игрок выбрал при входе в сетевую комнату).
- Устройство мастера не редактирует локальную копию: команда передаётся игроку, который сохраняет её в SharedPreferences. Если игрок отключился, команда не отправится.
- Журнал остаётся временным, только на время открытой комнаты.
- Сеть предназначена для доверенной локальной группы, без паролей/шифрования.
- Android APK не собирался в этой среде (Android SDK отсутствует). Проверены исходники сетевых классов Kotlin со stub-зависимостями и отдельные тесты формулы XP.
