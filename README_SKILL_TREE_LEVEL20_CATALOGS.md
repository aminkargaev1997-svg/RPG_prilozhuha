# RPG Creators — Skill Tree v1 + Level 20 + Catalogs

## Уровни и опыт
- Максимальный уровень персонажа: **20**.
- Формула XP для автоматического перехода: `650 + 750 * (level - 1)`.
- После 20 уровня XP **не пропадает**: каждые 14 900 XP (или настроенный вручную порог) дают **2 дополнительных очка древа**. Остаток XP сохраняется. Уровень остаётся 20.
- В карточке персонажа видно очки, полученные после 20 уровня.
- При загрузке прежних сохранений уровень ограничивается 20; новое поле `prestigePoints` по умолчанию равно 0.

## Древо v1
- В первой версии автоматически формируется 161 узел: центральный + 8 направлений по 20 шагов.
- Общее дерево из универсальных, расовых и классовых ветвей. Генерация стабильная для сочетания раса/класс.
- Узлы: малый (1 очко, с 1 ур.), значимый (2, с 4 ур.), ключевой (3, с 8 ур.), легендарный (5, с 15 ур.).
- Очки: 3 на 1 уровне, затем по 2 на уровень; дополнительные за XP после 20 уровня и награды мастера.
- Узел открывается только через соседний изученный узел, с учётом уровня и очков.
- Обычные численные бонусы прибавляются к **отображаемым итоговым** характеристикам; базовые хранятся отдельно.
- Ключевые/легендарные узлы описательные — их отыгрыш определяется мастером.
- Древо хранится в SharedPreferences отдельно по ID персонажа.
- Древо доступно в разделе «Играть» → «Древо навыков».

## Возможности мастера
- «⚙ Права» → «Использовать древо навыков»: в LAN игроки видят/не видят вкладку древа без потери изученных узлов. Выбор сохраняется на телефоне мастера.
- В окне управления персонажем вкладка «Древо»: просмотр изученных узлов, выдача +1/+5 очков, сброс, изучение доступных узлов от имени игрока.
- Операции мастера применяются и сохраняются на **телефоне игрока** через существующий механизм LAN-команд.
- Для совместимости все телефоны в комнате должны использовать новую версию приложения.

## Базы предметов и способностей
- Добавлено **200 шаблонов предметов** и **200 шаблонов способностей** в 10 жанрах.
- Каталог заполняет существующие поля, но не создаёт автоматически экипировку, свойства, активаторы и пассивные эффекты.
- Каталог есть в интерфейсе игрока и редакторе персонажа мастера.
- Можно редактировать и создавать свои предметы/способности.

## Проверка
- Kotlin/JVM: тест пройден для роста 19→20, переноса XP, получения очков за XP после лимита, ручного порога, генерации 161 узла и обоих каталогов по 200.
- Полный Android Gradle build **не выполнялся**: в текущей среде отсутствует Android SDK. Откройте проект через Android Studio, настройте `local.properties`/SDK и сделайте Build.

## Что не входит в v1
- Уникальные ручные деревья для каждой из сотен рас и классов.
- Анимированные иконки и полноценное копирование дизайна Path of Exile.
- Автоматизация сложных боевых событий (они остаются описательными).
- История изменения каждого узла и отдельный workflow подтверждения легендарных узлов.
