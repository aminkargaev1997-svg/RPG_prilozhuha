# RPG Creators: LAN UI + inventory

- Room IP and Wi-Fi information moved into an info dialog.
- LAN tab «Играть» renamed to «Персонаж»; duplicate Maps and Abilities buttons hidden within character screen.
- Network map supports landscape fullscreen, side panel with marker list and joystick outside map.
- Joystick moves own player or a selected shared marker. Tap on map no longer teleports player.
- Inventory item creation supports description. Tapping an item opens a dialog with «О предмете» action.
- Descriptions persist in local CharacterStorage; old items default to empty description.
- Shared map markers are session-only; character inventory is local and not synchronized.
- Android build and device tests not performed in this environment.
