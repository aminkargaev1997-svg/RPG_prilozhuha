# RPG Creators — исправления UI, выходов и истории героя (v2)

Основа: Adventure World v1 с журналом заданий, инвентарём и камерой.

## Что исправлено

1. **Окно NPC/метки.** Убрана колонка кнопок из узкого нижнего блока `AlertDialog`. Теперь отдельное адаптивное окно с группами действий и прокруткой описания. «Поговорить», «Ко всем», «Правка», «Двигать», «Удалить», «Закрыть» не должны накладываться друг на друга.
2. **Новая метка.** Отдельное окно с постоянными кнопками «Отмена»/«Сохранить» и прокручиваемой формой. Поля, библиотека меток и выпадающий список типа доступны и на небольших экранах.
3. **Обратный выход.** При первом переходе игрока через дверь/дом/магазин/портал автоматически создаётся метка «↩ Выход» на карте назначения. Она приводит к исходной карте и точке у исходного входа. Метка сохраняется в карте и общей модели приключения, синхронизируется с участниками, а мастер может её перемещать или настраивать. У метки стабильный ID на основе исходного входа — повторное посещение не создаёт копии и не отменяет перемещение мастера. Обратный выход может использоваться также для группового перехода.
4. **История появления героя.** Пассивные способности истории помечаются как `origin="hero_story"` и не удаляются через обычный режим «− Удалить» на экране игрока. Старые истории распознаются по прежним служебным описаниям. Мастер по-прежнему может править и удалять их через управление персонажем.
5. **Повторный рассказ по решению мастера.** В ночном разделе «Мир» все подключённые игроки доступны для запуска истории. Для уже прошедших отображается «Повторить». Повтор создаёт новую пару (дар + недостаток), *заменяя* предыдущие черты истории атомарной командой на телефоне игрока, без дублирования. Можно использовать, если старые черты уже удалены.
6. **Понятные поля для истории.** В форме мастера явно разделены «Дар героя» и «Недостаток героя» с названиями, объясняющими положительное и отрицательное действие, и подсказками.

## Что проверить

- NPC: открыть его окно как мастер и проверить все действия, включая «Ко всем»; проверить длинные описания.
- Новая метка: раскрыть тип, выбрать тип после открытия библиотеки, прокрутить форму, сохранить.
- Войти через дверь с назначенной второй картой. В появившейся метке «↩ Выход» выбрать «Выйти». Повторить переход; убедиться, что нет дублей. Мастер может передвинуть метку в разделе «Метки» на карте назначения. Повторный вход не должен вернуть её на прежнее место.
- В лагере после окончания дня выдать дар и недостаток. На телефоне игрока включить удаление способностей: защищённые пассивные черты должны остаться. В «Мир» повторить историю и убедиться, что новая пара заменила старую. Мастер может вручную удалить историю через редактор персонажа.
- Проверить переоткрытие комнаты мастером и повторное подключение игрока: созданный выход и черты должны сохраниться.

## Важно

- Для совместимости установите одинаковую версию приложения мастеру и игрокам.
- Новая метка выхода автоматически создаётся **при переходе** через настроенный объект; если игрок уже находится на карте из старой сборки, сначала вернитесь к исходной двери обычным способом мастера и войдите снова. Отдельного массового создания выходов для всех исторических переходов в этой версии нет.
- В случае удалённой исходной карты или двери мастер должен проверить/изменить связь обратного выхода вручную.
- Это исходный проект Android Studio. Полноценная Android Gradle-сборка здесь недоступна (нет Android SDK/дистрибутива Gradle). В изоляции с Kotlin-стабами успешно скомпилированы сетевой модуль, интерфейсы Adventure и обработчик мастерских правок. Проверка Android Compose на настоящем устройстве ещё требуется.
