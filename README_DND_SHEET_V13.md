# RPG Creators v13 — первый этап листа D&D

На основе LAN Auto Discovery v12. Добавлен отдельный «Лист D&D» в экране персонажа. Старые поля здоровья, опыта, инвентаря, древа и способностей сохранены.

## Новое
- Вкладка «Бой»: КД (ручное), инициатива (Ловкость + ручной бонус), скорость в футах, временные HP, кость здоровья и остаток костей, успехи/провалы спасбросков от смерти, состояния.
- Вкладка «Навыки»: автоматически рассчитанный бонус мастерства для уровней 1–20, необязательное ручное переопределение, владение шестью спасбросками и 18 навыками, пассивная внимательность.
- Вкладка «Магия»: характеристика заклинаний, Сл спасброска и атака заклинанием, концентрация, ячейки по девяти кругам (максимум/остаток), кнопки +/- и восстановление всех ячеек.
- Независимое сохранение листа по ID персонажа в SharedPreferences (`rpg_creators_dnd_sheets_v1`).

## Пока не реализовано
- Бонусы и параметры экипировки в формуле КД и характеристик; ввод КД ручной.
- Сетевая синхронизация новых полей с мастером.
- Автоматическая синхронизация «начала дня» с ячейками заклинаний; пока их восстановление ручное.
- Полноценная механика расхода ресурсов по активации способностей.
- Доработка инвентаря, валют и обмена — следующие этапы.

## Рекомендуемый тест
1. Открой персонажа, нажми «Лист D&D» и заполни все три вкладки.
2. Сохрани, выйди из приложения и проверь повторное открытие листа.
3. Измени Ловкость и проверь пересчёт инициативы при повторном открытии листа.
4. Для мага установи 3 ячейки 1-го круга, используй одну, сохрани и перезапусти приложение — должно остаться 2/3.
5. Проверь прокрутку на телефоне в вертикальном положении.

Полная сборка Android не выполнялась в текущей среде: нет Android SDK и требуемого дистрибутива Gradle 9.6.
