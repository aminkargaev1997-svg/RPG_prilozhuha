# Система уровней персонажа

- Начальный уровень: 1.
- Начальный опыт: 0/250.
- На экране персонажа доступны кнопки «Добавить опыт» и «Изменить максимум опыта».
- Опыт переносится через любое количество уровней за одно начисление.
- Пример: 0/250 + 500 опыта -> уровень 3, опыт 0/250.
- Если изменён максимум опыта, уже накопленный опыт пересчитывается по новому максимуму.
- Уровень, опыт и максимум сохраняются в локальных данных персонажа.
- При редактировании имени/расы/профессии прогресс не теряется.
- Старые персонажи получают уровень 1, опыт 0/250 при первом чтении старых сохранений.

Это исходники Android Studio; сборка APK на устройстве не проверена.
