# LAN: управление точками (обновление)

- Нажатие на СВОЮ точку: меню с кнопкой «Переместить».
- Нажатие на ЧУЖУЮ точку: только имя и кнопка закрытия, без перемещения.
- До выбора точки джойстик неактивен.
- После «Переместить» джойстик управляет выбранной точкой; «Готово» фиксирует её.
- Существующие обычные общие метки по-прежнему можно выбирать и перемещать.
- Полноэкранный горизонтальный режим: слева список меток, в центре карта, справа управление.
- Положение собственной точки сначала обновляется локально, затем передаётся по сети.
- Отправка движения ограничена примерно 25 сообщениями/секунду, сообщения клиента идут через одну очередь.
- Сервер уже привязывает сообщения move к идентификатору подключённого сокета, поэтому клиент не может передать координаты чужого персонажа через этот тип сообщения.

Ограничения: сборка Android APK и тест на телефонах в текущем окружении не проводились. Обычные общие метки не имеют владельцев и доступны всем игрокам. На сетевом уровне нет аутентификации.
