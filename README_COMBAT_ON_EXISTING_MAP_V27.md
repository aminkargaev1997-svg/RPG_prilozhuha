# RPG Creators v27 — боевой режим поверх существующей карты

## Зачем эта версия

Пробная перестройка UI боя без замены сетевой карты, камеры, жестов масштабирования,
джойстика, меток, HP меток, тумана войны, панелей мастера и прочих инструментов карты.
Кубики по-прежнему физические. Участники вводят только выпавшие значения.

## Новый сценарий

1. Создать или подключиться к LAN-комнате и загрузить карту.
2. Нажать «⚔ Бой» (мастер: боковая панель «Разделы → Бой»;
   игрок: прежняя кнопка «Бой»). Откроется **та же полноэкранная карта**.
3. Если бой не начат — откроется окно подготовки инициативы поверх карты.
   Мастер добавляет игроков/мобов и запускает бой; игрок вводит физический d20.
4. На карте появится маленькая строка текущего раунда, хода и действий.
   «Очередь» показывает инициативу; «Действия» разворачивает компактную панель.
5. Для атаки, способности, предмета или защиты нажать действие, при желании
   вписать вручную цель/результат физического броска и подтвердить (−1 действие).
6. Для перемещения подтвердить действие «Перемещение», затем пользоваться
   **прежним джойстиком**. Мастер контролирует допустимую дистанцию.
7. Закрыть панель кнопкой «Скрыть» или «✕». Карта остаётся на месте.
   В «Пульт и журнал» доступны прежние подробные функции v26.

## Что НЕ изменялось

- Сам `mapContent` (изображение/координаты/жесты/туман/маркеры) байт-в-байт тот же.
- Правила CombatEngine, LAN-команды и сетевое подтверждение действий.
- Кнопки камеры, джойстик, управление метками, HP, видимость и инструменты мастера.
- Базовый UI карты вне боя: новая панель скрыта, пока её не откроют.
- Старый CombatScreen остаётся запасным интерфейсом, если изображение карты отсутствует.

## Файлы

- `app/src/main/java/com/example/rpgcreators/MapCombatOverlay.kt` — новый HUD.
- `app/src/main/java/com/example/rpgcreators/LanGameScreen.kt` — подключение HUD
  и окна подробного боя, переадресация кнопок «Бой» на карту.

## Ограничения пробной версии

- Выбор цели непосредственно тапом по токену, вычисление попадания,
  автоматическое применение урона/лечения и эффекты на карте — не включены.
- Кнопки действий записывают факт действия/заметку и уменьшают счётчик,
  но не изменяют HP автоматически.
- Для начала нужна опубликованная карта и подключённая LAN-комната.
- Android SDK, Compose Gradle зависимости и эмулятор здесь отсутствуют;
  сборка и проверка на настоящих устройствах НЕ проводились.

## Быстрые ручные тесты

- Мастер и игрок подключаются. Проверить, что камера, туман и джойстик работают.
- Открыть «Бой» → окно инициативы поверх той же карты.
- Записать реальные результаты d20, начать бой, проверить общий порядок.
- Раскрыть/свернуть боевую панель — карта остаётся интерактивной.
- Игрок должен не иметь возможности тратить действия не в свой ход.
- Потратить «Перемещение» → попробовать джойстик, затем передать ход.
- Мастер переключает ход, возвращает действие, смотрит очередь.
- Свернуть карту → вернуться; вне боя обычная карта не имеет новой панели.
