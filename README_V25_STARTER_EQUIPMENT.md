# RPG Creators — v25. Стартовое снаряжение и размещение предметов

Основа: v24 (баланс древа навыков). Формат хранилища персонажей и инвентаря не изменён.

## Создание героя: шаг «Стартовое снаряжение»

- Убрали обычный **рюкзак** из стартового каталога и всех предложенных наборов. Инвентарь доступен сразу, без предмета-контейнера. Уже созданные предметы «Рюкзак» не удаляются.
- Вместо 13 прежних стартовых предметов: **20 предметов** с конкретными примерами применения (отмычки, лупа, компас, мел, зеркало, инструменты, оружие, припасы).
- Готовых наборов: **6** («Походный», «Выживальщик», «Учёный», «Следопыт», «Ловкач», «Боец») плюс «Свой набор». Каждый содержит пять типов предметов, оставляя одно свободное место. Лимит остался: **не более шести видов** стартового снаряжения.
- У расходников и стрел теперь есть стартовое **количество** (например, две повязки, десять стрел), которое видно в инвентаре и можно уменьшать вручную.
- Для оружия с уже известными шаблонами («Кинжал», «Посох», «Короткий меч», «Короткий лук») при создании героя сохраняются штатные описательные эффекты урона. **Кубики автоматически не бросаются.**
- Расход, свет, проверки инструментов, лечение и погода остаются действиями на усмотрение игрока и мастера — не автоматизированы.

## Инвентарь

- Для небольшого инвентаря начальные позиции карточек теперь располагаются по сетке, а не случайно. Это снижает вероятность перекрытий, особенно у новых героев со стартовым набором и двумя служебными предметами.
- Для 7–8 карточек высота поля увеличена до 280 dp. Перетаскивание оставлено; режим списка, поиск, сортировка и категории не изменены.
- Произвольно размещённые карточки внутри текущего экрана не сбрасываются от добавления вещи. Координаты перемещений не сохранялись между запусками ранее и по-прежнему не сохраняются.

## Совместимость

- У ранее созданных героев предметы, HP, способности, очки древа и сохранения **не пересоздаются**.
- Новые наборы применяются только в мастере создания нового персонажа.
- Расположение предметов при недостаточной ширине или при ручном перетаскивании может перекрываться; для большого количества вещей предусмотрен режим списка.

## Проверки

- `HeroCreationCatalog.kt` успешно скомпилирован отдельно на Kotlin/JVM с проверками каталога и наборов.
- Добавлены unit-тесты для стартовых предметов в `HeroCreationRulesTest.kt`. Полная сборка Android/Compose в контейнере недоступна: Android SDK и wrapper JAR отсутствуют.

## Что проверить в Android Studio

1. Создать нового героя с каждым из наборов, открыть инвентарь и проверить количество вещей.
2. Создать «Следопыт»: в инвентаре должны быть лук и стрелы ×10; у лука должно быть свойство урона.
3. Создать героя с «Ловкач»: должны быть обычные отмычки и кинжал со свойством урона.
4. Проверить обычное перетаскивание предметов и изменение количества расходников.
5. Открыть существующего персонажа v24 и убедиться, что его вещи не изменены.
