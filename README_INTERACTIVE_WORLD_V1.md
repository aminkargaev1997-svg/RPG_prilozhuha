# RPG Creators — интерактивный мир, первая тестовая версия

Создано на основе предыдущего полного проекта с деревом навыков, 20 уровнями и каталогами.

## Добавлено

- **Туман войны** для каждой сетевой карты. Мастер включает туман в окне карты, выбирает «Редактор», а затем пальцем стирает закрытые участки или возвращает туман. Никакой клеточной сетки не требуется: маска нормализована относительно изображения карты.
- **Ограничение движения** игроков в закрытые участки: сервер мастера проверяет всю линию от предыдущей до запрошенной позиции; метки игроков не могут пройти сквозь невидимый участок. Мастер может перемещать игроков независимо от тумана.
- **Сохранение тумана** на обоих телефонах и показ при офлайн-просмотре сетевой карты.
- Типы меток **NPC**, **Толпа**, **Записка**. NPC/Толпа открывают диалог, Записка показывает описание. Эти три особых типа могут создавать и редактировать только мастера.
- **Сетевые диалоги:** личное открытие, присоединение через ту же метку, общее обращение мастера «Ко всем», право говорить одновременно только одному игроку, завершение реплики/диалога, возможность мастера показать новые текстовые реплики. Голос остаётся живым, без записи и эмуляции бросков кубиков.
- Мастер может **редактировать текст и название** сетевой метки уже после создания.

## Как проверить

1. Установить одну и ту же новую версию приложения на оба телефона. Подключить в одну Wi-Fi сеть, создать LAN-комнату.
2. Мастер ставит метку NPC, указывает текст. Игрок нажимает на неё и «Поговорить». На другом телефоне «Присоединиться». Нажать «Сказать»; проверить блокировку кнопки у второго игрока. Мастер может освободить слово.
3. Мастер выбирает NPC и «Ко всем» — открывается разговор у всех подключённых участников.
4. Создать метку «Толпа» — участники могут прочитать разговор, но не могут говорить. Создать «Записка» — открывается подготовленное описание.
5. В окне карты включить «Туман». Мастер стирает участок пальцем; у игрока открываются те же части. Попытка игрока перейти в закрытую область должна блокироваться.
6. Мастер возвращает туман с помощью инструмента «Вернуть», переключает карты, возвращается, перезапускает комнату. Проверяет сохранение покрытия.
7. Игрок выходит из комнаты и открывает карту с пометкой «Сетевая» из библиотеки — закрытые области всё ещё скрыты.

## Ограничения прототипа

- Древо диалога с вариантами ответа отсутствует: текст задаёт мастер, игроки отвечают голосом.
- На данном этапе одна активная сцена разговора в комнате; приватный разговор не открывается автоматически на чужих устройствах, однако участники LAN обмениваются техническим состоянием комнаты.
- Записка не имеет отдельного декоративного шаблона документа; это текст в существующем окне метки.
- Ластик работает с маской разрешения 48×32: на очень больших изображениях граница будет ступенчатой.
- Тест fog-алгоритма пройден. Полная Android-сборка и тест на двух телефонах здесь не выполнены, поскольку в среде нет Android SDK/Gradle для проекта. Проверить компиляцию в Android Studio.
